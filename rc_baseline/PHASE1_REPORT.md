# DSP 第一阶段：单分支 RC 的 Python 适配与独立测试

日期：2026-10-16（America/Los_Angeles）。实验数据：index=509。正式配置：`configs/index509.json`；结果：`runs/index509_fixed_v1/results.json`。

## 结论

**已完成可信、可复验的单分支 RC 基线流程：真实数据加载、训练段同步与极性校正、共同前端、独立测试、模型与指标留档。** 这次是将 MATLAB 的单储备池机制适配为 NLTCP **S2S**，并非原64APSK W2S程序的逐位复刻，也不是双分支实验。

固定配置下，RC 在 RX1 上优于 LMS，在 RX2 和等权 X/Y 合并上均劣于 LMS。没有根据测试结果搜索参数、挑随机种子、重新训练或改变融合权重。

原 NLTCP 解码会产生4/5这样的非法 PAM4 判决，使原 `biterr` 自动扩展位宽。因此已经给出可复验的 MATLAB 口径 BER，同时明确报告固定2 bit目标下的范围；**尚不能把自动位宽数值不加说明地当成物理4 bit/复符号的最终 BER**。

训练目标是参考的真实I/Q数值；先预测六电平符号，再解码成PAM4整数，不把最终整数标签直接当RC训练目标。标签参考解码的首尾问题已在上一轮审计确认；本轮训练区内部映射再次通过，最终统一保护区也排除了首尾。

## 3. 接收流程与模型参数

```text
每个分段的RX实波形
  -> 训练段确定的lag/极性、训练RMS缩放
  -> 固定波形LMS/Volterra（仅训练段前10000采样更新）
  -> 训练区估计的波形RMS缩放
  -> CAP下变频 + RRC匹配滤波 + 每4点取1点
  -> 训练区估计的复符号RMS缩放
  +-> 25复符号窗口 -> 单分支tanh RC -> 岭读出 -> I/Q
  +-> 115抽头复数LMS -> I/Q
  -> 每种方法分别做固定0.5/0.5的RX1/RX2合并
  -> PAM6最近邻 -> 原NLTCP有记忆解码 -> BER/非法判决统计
```

|模块|固定设置|
|---|---|
|波形RX1|线性33抽头/步长0.022；二次17抽头/步长0.00008|
|波形RX2|线性43抽头/步长0.013；二次13抽头/步长0.00005|
|波形训练|前10000采样，单遍LMS；线性权重0，二次权重1e-7×单位阵；训练后冻结|
|CAP|RRC roll-off=0.105、span=10符号、sps=4、41系数、单位能量；载频=(1+0.105)/2+0.01=0.5625；phase=0|
|RC输入|25复符号居中窗口，50维交错I/Q；按训练有效窗口的绝对最大值缩放|
|RC状态|80节点；leak=0.7；谱半径0.9；uniform[-1,1]初始化；seed=100|
|RC更新|`r[t]=(1-0.7)*r[t-1]+0.7*tanh(A@r[t-1]+Win@[x[t];1])`|
|RC读出|特征 `[r(80),x(50),1]` 共131维；Wout为131×2；岭系数1e-5，包括偏置在内全维正则化|
|RC拟合|只在训练有效mask上解一次正规方程；A/Win固定不训练；输出不按测试RMS重新缩放|
|符号LMS|115复抽头，RX1步长0.0021/RX2步长0.0011；训练有效mask上单遍，随后冻结|
|X/Y合并|固定等权0.5/0.5；不使用测试BER、验证BER选通道权重|
|均衡前图|已经经过共同波形前端和CAP；另用训练段估计的单复数增益对齐尺度，不是原始示波器波形|

“均衡前后”指**符号均衡前后**，不把共同波形前端的改善全部归功于RC。LMS的115符号窗口与RC的25符号窗口并不匹配计算量，当前是保留来源参数的功能基线，不是等参数量/等延迟比赛。两者都含未来上下文，属于离线均衡。

## 4. 训练／验证／测试和边界

采用预先固定的连续分割，表中是1-based闭区间：

|分段|原始符号区间|真正计分/读出训练区间|有效复符号|参考比特数|
|---|---|---|---:|---:|
|训练|1–10000|129–9872|9744|38976|
|验证|10001–20000|10129–19872|9744|38976|
|独立测试|20001–51200|20129–51072|30944|123776|

每个分段独立执行对齐、滤波、窗口构造和RC状态递推，RC初始状态置零。两端各剔除128符号；配置检查保守叠加最大64采样对齐量、21采样前端半窗、5符号CAP半窗、57符号LMS半窗、13符号RC空转及1符号NLTCP前驱，需98符号，128足够。相邻计分区域间有256符号不评分区，任一有效窗口不会读入另一分段。NLTCP每段从头解码，评分起点之前已有预测前驱，未用真值初始化解码状态。

保护区是未评分/未拟合读出的同一分段上下文，不会从其它分段取数。RC递归记忆没有有限的硬截止，但因为分段独立重置，它不会携带训练段状态进入验证或测试。训练区缩放与参数是合法的已学习信息，不属于时序窗口跨界泄漏。

验证集只用于检查固定模型，本轮未据此搜索配置。训练后的权重先落盘并写冻结哈希，再计算验证和测试结果。测试全程只做transform/矩阵乘法/评价。上轮审计看过全文件结构与全序列相关；本轮实际参数计算重新限制在训练段，没有利用上轮测试段标签拟合。

## 5. 独立测试结果

下面两种BER口径必须一起阅读。原公式 `abs(q[n]-floor(q[n-1]/2))` 的输出可能是4或5。原 MATLAB `biterr` 未指定k，会随数据最大值决定二进制宽度。本轮每个通道/方法的两个分量在完整测试区均扩展到**3 bit/PAM4判决**；每分量分母92832，两分量合计185664。这并不是发射端真实的2 bit/PAM4。

固定2 bit区间以真实参考比特数123776为分母：合法判决精确计错；非法判决每个可能贡献0～2个未知比特错误。报告上下界而不捏造映射。这是确定性不确定范围，**不是统计置信区间**。

|输出|方法|MATLAB自动位宽BER|固定2 bit BER下界–上界|非法PAM4判决数|
|---|---|---:|---:|---:|
|RX1|符号均衡前|0.120966|0.172901–0.178734|361|
|RX1|符号LMS|0.043789|0.060836–0.064116|203|
|RX1|单分支RC|**0.035995**|**0.047764–0.051949**|259|
|RX2|符号均衡前|0.164092|0.222547–0.238382|980|
|RX2|符号LMS|**0.027561**|**0.037010–0.039919**|180|
|RX2|单分支RC|0.092657|0.119676–0.132554|797|
|X/Y等权合并|符号均衡前|0.110248|0.157114–0.162641|342|
|X/Y等权合并|符号LMS|**0.013605**|**0.019333–0.020060**|45|
|X/Y等权合并|单分支RC|0.037816|0.050002–0.054494|278|

固定2 bit计数：RX1 RC确定错误5912、上界6430；RX2 RC确定错误14813、上界16407；合并RC确定错误6189、上界6745。相应LMS为7530–7936、4581–4941、2393–2483。分母均为123776。原口径RC两分量错误数分别为RX1 3362/3321，RX2 8499/8704，合并3539/3482；每分量分母92832。

即使考虑非法输出的不确定范围，RX1 RC上界仍小于LMS下界，而RX2/合并RC下界仍大于LMS上界，因此**比较方向不依赖于非法判决采用哪种2 bit映射**。这证明了单分支流程可工作，但不支持“RC整体优于LMS”。RX2的较差成绩在训练和验证区已出现，不能归因于只在测试上意外掉点。25符号上下文相对LMS115抽头、固定单seed等是可能解释，尚未进行消融来确认原因。

|RC输出|训练BER（原口径）|验证BER（原口径）|测试BER（原口径）|
|---|---:|---:|---:|
|RX1|0.035577|0.038041|0.035995|
|RX2|0.089457|0.091321|0.092657|
|等权合并|0.036535|0.037579|0.037816|

## 6. MATLAB 与 Python 的关键差异

|项目|来源MATLAB|本实现|
|---|---|---|
|实验设定|64APSK W2S：25符号×4采样=100维，直接波形→符号|NLTCP S2S：CAP输出25复符号=50维；定位为符号级LMS替代|
|核心储备池|80节点、leak0.7、谱半径0.9、tanh、输入/状态/偏置读出|机制及主要参数保留；特征181维变为131维|
|标签|64APSK星座表构造I/Q，6bit整数评价|v1/v2的PAM6分量，后接NLTCP/PAM4评价|
|随机初始化|MATLAB rng(100)及其矩阵填充序|NumPy default_rng(100)；不保证A/Win与MATLAB逐元素相同，实际矩阵已保存|
|训练比例|前10%；“TEST”阶段又用全体标签重算Wout|前10000符号为训练区、内含保护mask；测试绝不拟合|
|边界与状态|零填充窗口、train/test重置但包含训练序列|每个split独立处理，128符号保护，固定共同评分mask|
|归一化|多处全序列RMS/max，包含测试；输出也归一化|一切缩放只由训练区确定，测试保持冻结|
|波形/符号LMS|返回边缘原信号、全局RMS缩放|零填充窗口，边界不评分；训练区估计输出尺度；更新式与共轭方向核查|
|CAP|MATLAB rcosdesign/conv/downsample|显式RRC公式+NumPy卷积/固定相位，单位能量；未声称已与MATLAB输出逐样本比对|
|判决平局|最近邻等距可能给向量导致赋值问题|固定选较小PAM6编号，不依据标签破平局|
|X/Y合并|用同一序列实测BER决定权重|固定0.5/0.5，避免测试标签参与合并|
|非法PAM4判决|biterr自动扩位，容易忽略语义|原数值保留；报告原口径和固定2 bit界限|

本机未实际运行MATLAB，因此当前证据是**源码机制复现＋数值单元验证＋真实数据独立测试**，不是 MATLAB/Python bit-for-bit 认证。若课程要求原W2S逐项复现，应单独建立64APSK index41对照任务或要求助教给出NLTCP W2S规格，不能把本次S2S成绩冒充成W2S成绩。

## 7. 第二组特征融合的接口和边界

当前已提供 `input(T,50)`、`states(T,80)`、`features(T,131)`、复数预测和最终state；模型可从NPZ恢复。详见README的 `ChannelPipeline`/`Reservoir` 接口。预测附件含全局0-based符号ID和有效mask，可以精确连接标签和两通道。

下一步可在每个物理通道内建立两个储备池：共享本轮冻结前端、同一输入、同一split；一条线性、一条tanh。拼接两条状态与一份共同输入/偏置，由共同岭读出输出I/Q。线性分支稳定性、两分支总节点预算及比较协议需要在训练/验证区确定。此阶段尚未创建线性分支、融合模型或运行任何融合训练。

建议先与助教确认非法PAM4判决的正式2 bit输出规则以及课程要求S2S还是W2S；这不影响已经保存的预测与状态接口，后续可在**不重新训练模型**的情况下按统一评价规则重算指标。若重算规则参考了本次测试表现，应明确记录，并为最终方案另留未看过的数据。
