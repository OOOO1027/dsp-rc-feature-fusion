# NLTCP非法PAM4输出与课程评价口径待确认事项

沿用原函数：先将预测I/Q最近邻判到PAM6编号q∈{0,…,5}，再计算d[t]=abs(q[t]−floor(q[t−1]/2))。前/当前q为(0,4)、(0,5)、(1,4)、(1,5)、(2,5)、(3,5)时会输出4或5。均衡误差改变当前或前驱PAM6判决会产生非法转换；不能当作正常PAM4符号强行截断或取模。

当前保持：合法判决按自然二进制精确计错；非法分量数U，每个未知2-bit输出可能贡献0…2错。N个复符号、合法比特错误E，固定2-bit BER范围为[E/(4N),(E+2U)/(4N)]，非法率U/(2N)。这不是置信区间，也不是对一个已定义合法解码器的唯一实测BER。MATLAB自动位宽BER另列：出现4/5时可能扩大为3位，I/Q位宽可不同，分母不再等于发射端实际比特数。

请助教明确：

1. 原有记忆解码公式是否是课程指定的最终接收算法？4/5应视为擦除、整符号错误、丢帧，还是应采用约束序列判决？若要求合法输出，请提供明确状态转移、代价、初态和终态，不应由我们依据测试标签选择映射。
2. 最终BER的分母是否固定每PAM4两bit、每复符号四bit？擦除对应两个bit是否都计错，还是另外报告擦除率？若允许剔除，必须同时报告覆盖率及原分母，不能通过丢弃坏点降低BER。
3. PAM4整数到bit是自然二进制还是Gray，I/Q如何复用？现有文件/代码使用自然二进制比较，需课程方确认。
4. 源标签首项缺前驱、末项与理想解码不一致如何定义？此前核对第1和51200项不一致；是否应丢保护区、补齐真实编码状态或修正参考文件？不要在测试中按答案重置解码器。
5. 当前/前驱判决错误造成的传播是否按解码后的逐bit结果计数？约束解码器如新增，允许的训练与验证范围、延迟、输出时序如何统一？
6. 各方法是否必须用同一同步、固定统计mask、同一解码器及边界规则？RX1/RX2与等权合并应分别解码后评价，避免混用位宽或统计区间。
